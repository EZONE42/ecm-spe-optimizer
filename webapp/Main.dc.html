KG14기 ECM 프로젝트 · 접근 방법 한 장 요약

2026-10-28

ECM을 ‘가상 셀’로 써서
최적의 고분자 전해질 조성을 찾는다

측정하지 않은 조성도 조성 → 물성 → ECM 파라미터 → 셀 성능으로 번역해 채점하고, 점수가 가장 높은 조성을 최적화로 찾는다.

기존 계획 · 진단형

측정된 셀 → ECM 분해 → 병목 판정

‘왜 느린지’는 알지만, 측정되지 않은 조성은 입력할 자리가 없다. 새 조성을 찾지 못한다.

새 계획 · 탐색형

조성 후보 → 가상 셀 채점 → 최적 조성

빠진 고리 ‘조성 → 물성’을 공개 ML·MD 데이터가 채우고, 병목 분석은 목표 사양서로 앞단에 둔다.

파이프라인 7단계

① 조성 공간 정의

바꿀 변수와 범위: 고분자 종류·분자량, 염(LiTFSI/LiFSI), EO:Li, 가소제 비율, 온도

팀 결정

② 조성 → 물성 예측

VTF-ML: 조성으로 A·B·T₀를 예측 → 어느 온도의 σ든 계산. t⁺도 예측

CheMixHub 11,350행 · HTP-MD 6,057종

③ 앵커 보정

MATLAB EIS 피팅으로 실측 R·C → σ를 ‘정답’으로 삼아 예측 오차 확인

Zenodo KIT EIS 원자료

④ 물성 → ECM

막 R_b, 양극 이온 경로(전송선 모델), 농도분극, 계면 저항으로 번역

계획서 3장 식

⑤ ECM → 셀 성능

Simulink 2RC로 후보마다 가상 방전: 1C·25°C에서 꺼낼 수 있는 용량·에너지, 발열

공통 셀 설계 (양극 60 µm 등)

⑥ 최적화

목적: 1C·25°C 에너지 최대. 제약: 액체 함량 5% 또는 20% 이하, 전위창. 격자 탐색 → 베이지안 최적화

②~⑤를 반복 호출

⑦ 검증·제안

논문 묶음을 빼고 학습해 실제 셀 성능 순위를 맞히는지 시험 → 상위 후보 3~5개 ± 신뢰구간

다음 실험 후보

반복 루프: ⑥ 최적화기가 다음 후보 조성을 제안하면 ②→⑤가 다시 채점한다. 병목 분석의 민감도 결과는 ⑥의 목적함수 가중치(예: t⁺가 결정적이면 t⁺ 반영 강화)로 들어간다.

ECM이 맡는 세 역할

채점기 · Simulink

물성을 셀 성능(에너지·전압 손실·발열)으로 번역해 후보를 같은 기준으로 비교

정답 앵커 · MATLAB 피팅

실측 EIS에서 R·C를 뽑아 ML 예측이 얼마나 맞는지 보정 (평가표 2번)

목표 사양서 · 병목·민감도

어떤 물성이 성능을 가장 크게 바꾸는지 먼저 찾아 최적화 목표를 정함

핵심 식

σ(T) = A·T⁻¹ᐟ²·exp(−B/(T−T₀))

VTF: 조성 → A·B·T₀ → 온도별 전도도

R_b = L / σ

막 저항 (Ω·cm²), L = 두께

R_conc ≈ R_b·(1/t⁺ − 1)

낮은 t⁺가 만드는 ‘보이지 않는 막 저항’

V = OCV − I·R₀ − V₁ − V₂

2RC 셀 모델: 가상 방전 곡선

max J = E(1C, 25°C)

제약: 액체 함량·전위창

말할 수 있는 것

“학습 데이터 범위 안에서, 우리 셀 설계에 최적인 조성은 ○○, 예측 오차 ±○배. 다음 실험 후보 3개를 제안한다.”

말할 수 없는 것

데이터에 없는 완전히 새로운 화학 구조의 성능 보장. 이건 실험 제안으로 넘긴다.

선택: 인시츄 겔(DOL계) 비교
